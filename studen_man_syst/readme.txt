
=========================================
🎓 Student Management System (Python + Streamlit + MySQL)
=========================================

This is a simple web-based Student Management System built using Streamlit and MySQL. 
It allows users to add, view, search, and delete student records from a MySQL database 
through a user-friendly interface.

-------------------------
📌 Features:
-------------------------
- Add new student with name, age, and grade
- View all student records
- Search students by name
- Delete students by ID
- Responsive Streamlit UI

-------------------------
🛠️ Technologies Used:
-------------------------
- Python
- Streamlit
- MySQL
- mysql-connector-python

-------------------------
💾 Requirements:
-------------------------
- Python 3.x installed
- MySQL installed and running
- Streamlit installed (`pip install streamlit`)
- MySQL Connector for Python (`pip install mysql-connector-python`)

-------------------------
⚙️ Setup Instructions:
-------------------------
1. Start your MySQL server.
2. Create a MySQL database named `school`:
   CREATE DATABASE school;

3. Update the MySQL credentials in the Python code if needed (host, user, password).
4. Save the code in a file named managment.py.
5. Run the app:
   streamlit run managment.py
